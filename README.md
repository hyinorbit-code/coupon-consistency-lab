# Coupon Consistency Lab

한정 수량 쿠폰의 발급·사용·취소·만료·정산을 통해 **동시성, 데이터 정합성, 비동기 처리의 신뢰성, 성능 개선을 검증하는 Java/Spring 백엔드 프로젝트**입니다.

## 현재 상태

2026-10-30: 기획 문서만 작성했습니다. 애플리케이션, 배포, 성능 실험은 아직 구현하거나 실행하지 않았습니다. 본 문서의 수치와 시나리오는 계획이며 실적이 아닙니다.

## 목적

기존 Java/Spring 기능 개발, SQL 개선, 배치·워커·다중 서버 연동 경험을 기반으로 JPA, Redis, Kafka, 테스트, 클라우드 배포와 정량적 검증 역량을 보완합니다. 실제 사용자 확보는 필수 목표가 아닙니다. 직접 배포하고 통제된 부하·장애 실험으로 검증합니다. 실험 경험과 실제 고객 서비스 운영 경력은 구분합니다.

| 사례 | 질문 | 결과물 |

| 비동기 신뢰성 | 종료·중복 전달·중단 이후에도 사용·정산 결과가 맞는가? | 장애 재현, 멱등성, 누락 복구 기록 |

## 진행 원칙

작은 정상 동작 버전 → 문제 재현 → 대안 비교 → 개선 → 회귀 검증 → 문서화 순서로 진행합니다. 기술은 관찰한 문제를 해결할 때 추가합니다. 기능 수보다 재현 가능한 실험과 설계 판단을 우선합니다.

## 예정 기술

Java/Spring Boot, JPA, 관계형 DB를 시작점으로 삼습니다. Redis와 Kafka는 후속 실험 단계에서 도입합니다. 구체적인 버전, DB, 빌드 도구, 클라우드와 모듈 구조는 아직 정하지 않았습니다. Kubernetes와 서비스 분리는 필요가 입증되면 검토합니다.

## 실행 방법

아직 실행 가능한 코드가 없습니다. 첫 구현 이후 실제로 검증한 실행·테스트·배포 명령을 이 절에 추가합니다.
